# LOST & FOUND Cell – GLA University

A centralized web portal to manage lost and found items across GLA University. This system ensures smooth reporting, tracking, and handover of lost items through an admin-verified workflow.

## 🚀 Features

- 📦 **Item Submission**: Admins can register found items with photos and details.
- 🔍 **Search & Filter**: Students can browse or search for lost items by category, date, and location.
- 🛡️ **Claim Process**: Students can claim items by submitting verification details.
- 🤝 **Admin Verification**: Admins review claims and upload proof of handover upon verification.
- ⏳ **180-Day Policy**: Unclaimed items are listed for 180 days before being moved to the donation section.
- 📤 **Donation Page**: Unclaimed items are showcased for social redistribution.

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Bootstrap (or Tailwind)
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Authentication**: Basic login for admins, student verification (can be extended)

## 🧑‍💼 User Roles

- **Admin**:
  - Add/view/edit item records
  - Review and approve claims
  - Upload proof after handover

- **Student**:
  - View available lost items
  - Submit claim with details
  - Get admin contact info if approved
